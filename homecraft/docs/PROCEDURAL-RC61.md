# Procedural graphics migration – RC61 integration candidate

Based on RC60 (3bae596). This is not a certified RC80 release.

- Live village scene now uses noise-based procedural PBR data maps, 512px grass and road textures, four instanced wind grass variants, flowers and clover, shared tree/bush geometry with three distance/quality LODs, road shoulder geometry and localized wet roughness. Park trees replace their old visuals at the existing positions; far forest still uses existing instancing.
- Park benches, park lamp positions and local point lights, roof edge modules. Existing building footprints and doors retain their gameplay. A hinge-local door and stone wall factory are supplied but not placed in the live town. Existing procedural facade remains in use.
- Character generation no longer downloads a GLB. A module worker transfers the existing connected weighted skin with named morphs to the main thread; the procedural articulated fallback stays visible. Two source qualities are cached. The optional npm run assets:export remains available. Existing saved profile fields, 42 named bones, eight clips and six morphs remain. No new 3-tier complete humanoid LOD or verified triangle budget; existing near/far update throttling remains. Existing hair, clothes, faces and hands are reused.
- Live NPC dialogue uses greeting and bounded speech animation, quaternion-based yaw interpolation, and eased camera arrival/return. The existing relation, dialogue text and save flow remain.
- Graphics panel exposes renderer draw calls, triangles and estimated frame interval; medium PCF shadow map 512. These are diagnostics, not a benchmark. Existing graphics, weather, vehicle and house planning systems are retained.

## Verification gates
Added tests for texture tiling, variant geometry, shared resources, LOD, road profile, character buffer codec, camera/gestures, props and updated the existing browser smoke expectation for procedural skin. Existing build and smoke workflow should run on the branch; confirm results in Actions before merging. Android device performance (30 FPS), actual frame timing, exact character triangle budgets, WebView offline worker and visual approval are outstanding. No APK is claimed until CI succeeds. No external assets required at runtime by the migrated scene. Additional requested features outstanding: full 3-tier character mesh LOD, IK foot placement, complete material/texture registry across all subsystems, chunk streaming and adaptive resolution, all road intersections and curb ramps, exact foliage collision clearance/visual QA, complete new face/body sculpt and independent terrain verification. The current implementation is an integration pass rather than a finished visual overhaul.
