# RC82 – ensure the new model is loaded in the game
RC81 passed CI, but the in-world browser smoke test did not require the active player's continuous skinned outfit; only the profile preview did. Runtime worker generation may leave the old segmented model visible for up to 90 seconds or longer after failure. RC82 generates the same weighted geometry during the build into two compact offline binary caches (not external GLB files), packages them with PWA/APK, and loads those first. The worker remains a recovery route. The live HUD shows the actual version and model status; a closer default third-person camera makes the figure easier to inspect. CI now waits for the packaged continuous model in the live scene and saves a landscape screenshot. No claim of photorealism or device-specific verification.
