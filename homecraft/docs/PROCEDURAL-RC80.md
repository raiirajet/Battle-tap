# RC80 – integrated procedural graphics release candidate
## RC67–80 acceptance checklist
67 hands: individual curls, greeting spread, nails. 68 clothing: shaped cloth folds. 69 physique: local torso profiles. 70 motion: distance-driven articulated gait and ankle pivot. 71 outdoor player sagittal two-link leg IK (not world-space foot lock). 72 daylight and NPC contact shadows. 73 layered procedural clouds. 74 wave normals and rain shader. 75 clearcoat cars, treads, exterior details, cockpit. 76 rounded furniture and wood/textile detail. 77 park planters and bin. 78 resolution cap, p95, adaptive vegetation budget. 79 WebGL context loss/restoration handlers, input reset and bounded generation retry. 80 version, automated build gate, offline worker verification, dialogue screenshot, shader error detection and existing Android package checks.
## Limitations and gates
RC80 is a release candidate, not a confirmed device-tested release. Previous RC66 passed CI including APK signature and target SDK checks. New RC80 unit, browser, offline and Android build results must be checked on its exact commit. Human visual approval and measured 30 FPS on a real Android device are mandatory before production merge; neither is established by source changes or CI. No claim of photorealistic assets, exact triangle budget, full rig retargeting, phoneme lip sync, physical puddles, or whole-world streaming. The new IK is restricted to detailed outdoor player and the new NPC buildings are decorative. No saved data schema changes or gameplay rules changed intentionally. Android recovery handles a restorable WebGL context, not full OS process termination. Keep RC66 APK for rollback and existing RC60 branch untouched.
