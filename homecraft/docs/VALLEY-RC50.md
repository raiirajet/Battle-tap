# RC50 — character anatomy and wardrobe refinement
Shared face relief for GLB and fallback heads, cheek/nose/chin shading, matching UV seam normals, brows, ear contours, softer lips, one articulated ponytail and a separate braid, finger crease details, more distinct body depth, garment cuffs and lapel edges, bevelled shoes with eyelets and crossed laces, and a larger lit interactive character preview with walking/running. Existing six presets, local saved data, 42-bone rig and 8 animation clips retained. No new external dependencies. New regression tests are included. Procedural meshes remain approximations of the visual reference, not hand-sculpted photorealistic characters. On-device rendering and CI results must be verified before release.
