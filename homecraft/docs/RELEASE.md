# Release checklist
The normal HomeCraft workflow builds a debug APK. A production APK must use a persistent signing key controlled by the repository owner. Configure repository Actions secrets HOMECRAFT_KEYSTORE_B64 (base64-encoded keystore), HOMECRAFT_KEYSTORE_PASSWORD, HOMECRAFT_KEY_ALIAS, HOMECRAFT_KEY_PASSWORD. Do not paste secrets into chat or commit them. Run the manual HomeCraft signed release APK workflow after its workflow file is available on the default branch and choose the desired HomeCraft ref. Keep an offline backup of the signing key. Existing debug APKs may need uninstall/reinstall; export projects first. Signatures do not certify app quality or security. Before distribution, perform physical Android device tests for biometric enrollment/cancellation, restart unlock, import/export and 3D memory performance. Never publish a debug APK as a production release.
