# HomeCraft 3D – development preview 0.3.0
Independent Android/PWA application. Package ch.homecraft.planner. No changes to the games. German interface.
Run: npm install; npm test; npm run dev. Android: npm run build; npx cap add android; npx cap sync android; cd android && ./gradlew assembleDebug.
Implemented in source: local project manager, undo/redo, rectangle and connected wall drawing, numeric wall and opening edits, bounded rectangular wall voids, closed polygon room detection for joined segments, real Three.js meshes, 22 procedural furniture types, multiple levels, simple bounding-box roof, garden ground, orbit and walking with wall collisions, project/SVG/GLB/PNG exports, basic flooring cost, light/dark app shell. PWA service worker.
Not release-ready: no validated Android hardware run yet. localStorage not SQLite/IndexedDB; no automatic intersection splitting, robust junctions or curved walls; no exact roof fitting for complex shapes, stair openings or stair navigation, furniture collisions, realistic GLB asset library, 795 models/120 materials/60 templates, material editor, blueprint import, PDF export, full MEP, advanced kitchen/bath tools, lighting simulation, accessibility audit, biometric lock, release signing, complete mobile gestures or performance benchmarks. Do not treat partial implementations as masterplan completion. No engineering or building-code validation.

## 0.4.0
Adds non-destructive planar wall intersection/T-junction splitting for room detection, overlapping-wall rejection, named rooms and 8 floor color presets, 3 editable starter templates, upper-floor mesh openings for valid straight stairs, touch pinch/pan, manual annotations and measurements, raster image tracing, and vector A3 PDF export. Room metadata is keyed by contour and may reset when topology changes. Image tracing uses whole-image width, not two-point calibration. Stair movement, full slabs/ceilings, complex roof geometry, PDF import and textured assets remain incomplete. PDF uses ASCII text fallback. No full masterplan completion claimed.

0.4.1: two-point raster calibration, offset adjustment, transparent room overlay, procedural floor textures, straight staircase walking with level transitions and basic furniture collisions. Not yet validated on real devices. The stair cutout remains a floor-plane opening, not a complete structural slab. Stair walk is limited to linked straight runs. Imported plan image remains locally stored; export your project as backup.
