# Crownfall 3D Asset Pack 0.2
Enhanced procedural GLB production prototype based on Visual Production Bible 2.0 pp. 5–19, 20–56, 62–68. Embedded 128px procedural base-colour, normal and ORM textures, UVs, smooth curved geometry, trim/detail geometry, all 56 buildings with four pre-completion phases, six distinct wonders with three phases, vegetation/rocks/water, encounter prefabs, inventory meshes and additional work/carry clips. Rebuild via node crownfall/tools/asset3d/generate.mjs crownfall/assets/3d and validate.mjs. ZIP is published by Actions. Not a final semi-realistic asset set: no high-resolution hand-painted atlases, deformation skinning, final LODs, exact character likeness, IK, tested collision or rendered UI icons; generic building construction variants and many simplified silhouettes remain. No runtime integration or device acceptance.
