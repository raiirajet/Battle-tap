# Crownfall 3D Asset Pack 0.1
Source: 3D Visual Production Bible 2.0 pp. 3–16, 19–33, 37–54, 62–64. Run `node crownfall/tools/asset3d/generate.mjs crownfall/assets/3d` from repository root, then `node crownfall/tools/asset3d/validate.mjs crownfall/assets/3d`. CI publishes the resulting asset pack as a ZIP. Geometry is true glTF 2.0 GLB, meters/Y-up, with material factors and animated node hierarchies. This is a first production prototype: humanoids use rigid articulated parts (not smooth skin weights), in-place animation, and no foot IK. No PBR texture maps, final LODs, KTX2, full construction/upgrade variants, six unique wonders, inventory catalog, final UVs, or device/engine acceptance. Buildings are individual catalogue IDs with simplified shared architectural families, not hand-sculpted finished assets. Models are not integrated into the current Canvas game. No AI concept images are treated as models. Manifest includes hashes, IDs, clips, material slots and available sockets.
